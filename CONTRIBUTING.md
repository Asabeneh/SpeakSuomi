# Contributing to Finnish Flow

Thanks for helping improve Finnish Flow. This project is a small static site — contributions should be lightweight and focused.

Guidelines

- Edit content in `index.html`. Keep changes minimal and local to the section you update.
- For the placement test, edit the assessment tables (they are visually hidden by default). The interactive quiz engine parses those tables automatically.
- Keep CSS changes scoped; avoid global resets unless necessary.
- Test changes by opening `index.html` in a browser or running a local server.

Submitting changes

- Use a branch per feature or content update.
- Open a PR with a short description of what changed and why.
- For content edits, include a brief proofread pass (grammar/spelling) and verify layout on narrow screens.

Reporting issues

- Create an issue describing the problem, include browser + OS, and steps to reproduce.

Formatting

- HTML: keep indentation consistent with the existing file (2 spaces inside tags).
- CSS: append new rules near the relevant section of the stylesheet.
